# PuzzleAR Kotlin

**PuzzleAR** — Android-приложение с дополненной реальностью, в котором пользователь собирает пазлы и открывает 3D-фигурки. Проект разработан на Kotlin с использованием EasyAR Sense SDK и OpenGL ES.

## О проекте

Основная идея приложения — объединить классическую механику сборки пазлов с технологиями дополненной реальности. Пользователь может выбирать изображения и уровень сложности, собирать пазлы, получать виртуальные фигурки и пополнять ими собственную коллекцию.

Приложение демонстрирует применение AR-технологий, работу с трёхмерными моделями и разработку интерактивного пользовательского интерфейса для мобильных устройств.

## Возможности приложения

### Главное меню
- Запуск AR-сессии.
- Переход к коллекции фигурок.
- Просмотр истории игровых сессий.
- Переход к настройкам приложения.

### AR-пазл
- Сборка пазлов с использованием дополненной реальности.
- Выбор изображения для сборки.
- Три уровня сложности: 3×3, 4×4 и 5×5.
- Регулировка затемнения области под игровым полем.
- Взаимодействие с элементами игрового поля.
- Отображение результатов после завершения сборки.

### Коллекция фигурок
- Просмотр открытых 3D-фигурок.
- Отображение миниатюр моделей.
- Просмотр прогресса открытия коллекции.
- Переход к таблице рекордов.

### Система рекордов
- Сохранение лучшего времени прохождения.
- Сохранение минимального количества ходов.
- Отдельные результаты для каждого изображения и уровня сложности.
- Просмотр результатов по уровням 3×3, 4×4 и 5×5.

### История
- Сохранение истории игровых сессий.
- Просмотр предыдущих результатов.

### Фотографии
- Возможность сохранять фотографии с AR-объектами.

## Архитектура приложения

Проект организован по функциональным пакетам. Каждый пакет отвечает за отдельную часть приложения, что упрощает поддержку и дальнейшее расширение проекта.

### Структура исходного кода

```text
cn.easyar.samples.helloar/
```

### Взаимодействие компонентов

Основной сценарий работы приложения:

1. `MainActivity` предоставляет пользователю доступ к основным разделам приложения.
2. При запуске игры открывается `ARActivity`, которая организует AR-сессию.
3. `PuzzleCatalog` загружает доступные пазлы из ресурсов приложения.
4. `PuzzleInfo` содержит параметры конкретного пазла, а `PuzzleSettings` — настройки игрового процесса.
5. `PuzzleBoard` управляет игровой логикой и состоянием сборки.
6. Компоненты `render` отвечают за графическое отображение игрового поля и его элементов.
7. Компоненты `model` загружают, обрабатывают и отображают 3D-модели.
8. Компоненты `data` сохраняют прогресс, историю и рекорды пользователя.
9. Экраны коллекции, истории и рекордов используют сохранённые данные для отображения результатов.

## Используемые технологии

- **Kotlin** — основной язык программирования.
- **Android SDK** — разработка Android-приложения.

- **OpenGL ES** — отрисовка графики и трёхмерных объектов.
- **GLB / glTF** — формат трёхмерных моделей.

## Добавление новых пазлов и 3D-моделей

Все ресурсы пазлов располагаются в каталоге:

```text
app/src/main/assets/puzzles/
```

Каждый пазл хранится в отдельной папке. Название папки используется как идентификатор набора.

### Структура папки пазла

Для добавления нового пазла создай папку с уникальным названием и помести в неё три файла:

```text
assets/
└── puzzles/
    ├── existing_puzzle/
    │   ├── target.jpg
    │   ├── info.txt
    │   └── model.glb
    │
    └── my_puzzle/
        ├── target.jpg
        ├── info.txt
        └── model.glb
```

Назначение файлов:

| Файл | Назначение |
|---|---|
| `target.jpg` | Изображение, из которого формируются элементы пазла |
| `info.txt` | Название пазла и дополнительные параметры отображения фигурки |
| `model.glb` | 3D-модель фигурки, которая отображается в AR |

### 1. Изображение `target.jpg`

Добавь изображение, которое пользователь будет собирать в виде пазла.

Требования:
- Формат файла — JPG.
- Имя файла должно быть именно `target.jpg`.
- Изображение должно находиться непосредственно в папке нового пазла.

### 2. Описание `info.txt`

Файл `info.txt` содержит параметры нового пазла. Он позволяет задать название, скрыть лишние узлы модели и настроить её отображение.

Пример содержимого:

```properties
title=Название
hide=Имя.узла1,Имя.узла2
rotate=180
scale=1.2
```

Описание параметров:

| Параметр | Назначение |
|---|---|
| `title` | Название пазла, отображаемое в приложении |
| `hide` | Имена узлов 3D-модели, которые нужно скрыть |
| `rotate` | Поворот модели в градусах |
| `scale` | Коэффициент изменения размера модели |

**Подробнее о параметрах:**

- `title=Название` — задаёт название фигурки или пазла.

- `hide=Имя.узла1,Имя.узла2` — позволяет скрыть лишние объекты внутри 3D-модели. Это полезно, если модель состоит из нескольких частей и некоторые из них мешают отображению фигурки или делают её визуально слишком маленькой. Имена узлов нужно брать непосредственно из структуры GLB-модели. Если скрывать нечего, параметр можно не указывать.

- `rotate=180` — поворачивает модель на 180 градусов. Используется, например, если фигурка отображается спиной к пользователю. Значение указывается в градусах.

- `scale=1.2` — изменяет размер модели. Значение больше 1 увеличивает модель, а значение меньше 1 уменьшает её. Например, `scale=0.8` уменьшит модель, а `scale=1.5` увеличит.

Если дополнительная настройка не нужна, соответствующую строку можно не добавлять.

### 3. 3D-модель `model.glb`

Помести в папку пазла 3D-модель в формате GLB.

Важно:
- Имя файла должно быть именно `model.glb`.
- Модель должна быть совместима со встроенным загрузчиком GLB.
- При необходимости настройки отображения модели можно задать через `info.txt`.
- Учитывай размер модели: слишком тяжёлые файлы могут увеличить время загрузки и повлиять на производительность приложения.

### 4. Проверка нового пазла

После добавления ресурсов:

1. Убедись, что папка находится внутри `assets/puzzles/`.
2. Проверь наличие `target.jpg`, `info.txt` и `model.glb`.
3. Проверь правильность написания имён файлов и параметров.
4. Убедись, что идентификатор папки уникален.
5. Пересобери и запусти приложение.
6. Проверь появление нового пазла, сборку изображения и отображение соответствующей 3D-фигурки.

Загрузкой доступных наборов занимается `PuzzleCatalog`, поэтому при добавлении новых пазлов важно соблюдать принятую структуру ресурсов и формат описания.

## Запуск проекта

### Требования

- Android Studio.
- Android SDK.
- JDK, совместимый с используемой версией Gradle.
- EasyAR Sense SDK.
- API-ключ EasyAR.

### Настройка EasyAR

Для работы AR-функциональности необходимо получить API-ключ EasyAR.

В корне проекта открой или создай файл `local.properties` и добавь строку:

```properties
easyar.key=put_your_key_here
```

Замени `put_your_key_here` на собственный API-ключ EasyAR.

**Важно:** `local.properties` содержит локальные настройки разработчика и не должен публиковаться в GitHub. Не добавляй настоящий API-ключ в репозиторий.

### Установка и запуск

1. Склонируй репозиторий:

   ```bash
   git clone https://github.com/dareart03/PuzzleARKotlin.git
   ```

2. Открой проект в Android Studio.

3. Настрой `local.properties`, указав API-ключ EasyAR.
   
4. Добавь по примеру папку со своим паззлом в `app/src/main/assets/puzzles/`

5. Дождись синхронизации Gradle.

6. Подключи Android-устройство и запусти приложение через Android Studio.

### Сборка через терминал

Для Windows PowerShell:

```powershell
.\gradlew.bat :app:assembleDebug
```
