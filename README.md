# PuzzleARKotlin

**PuzzleARKotlin** — Android-приложение с дополненной реальностью (AR), в котором пользователь собирает пазлы из частей изображения и открывает трёхмерные фигурки. Для распознавания изображений и отображения 3D-моделей используется EasyAR Sense.

Приложение можно скачать на телефон по ссылке: [PuzzleAR (GitHub Release)](https://github.com/dareart03/PuzzleARKotlin/releases/tag/v1.0)

## Возможности

- **Дополненная реальность:** распознавание изображений-мишеней и отображение соответствующих 3D-моделей.
- **Пазлы:** четыре уровня сложности — 3×3, 4×4, 5×5 и 6×6.
- **Настройки игры:** выбор размера сетки и регулировка затемнения под игровым полем.
- **Игровой интерфейс:** отображение количества ходов и времени, подсказки, перемешивание элементов и возможность сделать фотографию.
- **Коллекция:** просмотр открытых фигурок и силуэтов ещё не найденных моделей.
- **Рекорды:** сохранение лучшего времени и минимального количества ходов отдельно для каждого пазла и размера сетки.
- **История:** список игровых событий с миниатюрами собранных пазлов и сохранённых фотографий.
- **Сохранение прогресса:** результаты и состояние коллекции сохраняются между запусками приложения.
- **Интерфейс:** единое тёмное оформление с фиолетовыми акцентами, скруглёнными карточками и кнопками.

## Технологии

- Kotlin
- Android SDK
- EasyAR Sense SDK 4.11
- OpenGL ES
- GLB / glTF — форматы 3D-моделей
- Android XML Layouts
- SharedPreferences и локальное хранение данных

### Принцип организации

Проект разделён на несколько логических частей, каждая из которых отвечает за определённую область приложения.

- **AR** отвечает за взаимодействие с EasyAR, камерой и AR-сценой.
- **Data** отделяет хранение истории, прогресса и рекордов от пользовательского интерфейса.
- **Model** содержит инструменты для загрузки, преобразования и отображения трёхмерных объектов.
- **Puzzle** реализует механику пазлов и управление их параметрами.
- **Render** отвечает за графическую отрисовку игрового поля и его элементов.
- **UI** объединяет экраны приложения и обработку пользовательских действий.
- **Util** содержит вспомогательные функции, используемые разными частями проекта.

Такое разделение упрощает поддержку приложения и позволяет изменять отдельные компоненты без необходимости переписывать всю логику.

- JDK, совместимый с используемой версией Gradle;

Для работы AR-функций потребуется Android-устройство с поддержкой необходимых возможностей камеры и графики.

## Настройка EasyAR

Перед запуском приложения необходимо указать собственный ключ EasyAR.

1. Откройте корневую папку проекта.
2. Найдите файл `local.properties`.
3. Добавьте в него строку:

```properties
easyar.key=put_your_key_here
```

4. Замените `put_your_key_here` на действительный ключ EasyAR.
5. Синхронизируйте Gradle и запустите приложение.

**Важно:** файл `local.properties` содержит локальные настройки разработчика и не должен добавляться в Git. Не публикуйте свой ключ EasyAR в открытом репозитории.

## Добавление новых пазлов и 3D-моделей

Каждый пазл хранится в отдельной папке внутри:

`app/src/main/assets/puzzles/`

Пример структуры:

```text
assets/
└── puzzles/
    ├── wanderer/
    │   ├── target.jpg
    │   ├── model.glb
    │   └── info.txt
    │
    └── new_puzzle/
        ├── target.jpg
        ├── model.glb
        └── info.txt
```

Для добавления нового пазла создайте папку с уникальным идентификатором. В неё необходимо поместить три файла.

### 1. target.jpg

Изображение, которое будет использоваться в качестве AR-мишени и основы пазла.

Поддерживаемые форматы изображений: JPG, JPEG и PNG.

### 2. model.glb

3D-модель, которая будет отображаться после распознавания изображения с помощью EasyAR.

Модель должна быть подготовлена в формате GLB и содержать необходимые материалы и текстуры.

### 3. info.txt

Файл с дополнительными параметрами пазла и 3D-модели.

Пример:

```properties
title=Название персонажа
hide=Имя.узла1,Имя.узла2
rotate=180
scale=1.2
```

Описание параметров:

| Параметр | Назначение |
|---|---|
| `title` | Название пазла, отображаемое в приложении |
| `hide` | Список узлов модели, которые необходимо скрыть, через запятую |
| `rotate` | Дополнительный поворот модели в градусах |
| `scale` | Коэффициент изменения масштаба модели |

Параметры `hide`, `rotate` и `scale` необязательны. Если дополнительная настройка не требуется, их можно не указывать.

Например, если модель отображается слишком маленькой, можно увеличить её масштаб:

```properties
scale=1.5
```

Если модель повёрнута в неправильную сторону:

```properties
rotate=180
```

Если в модели присутствуют лишние узлы:

```properties
hide=Node1,Node2
```

После добавления файлов приложение должно обнаружить новый пазл через каталог ресурсов.

**Важно:** идентификатор папки должен быть уникальным. Не используйте одинаковые идентификаторы для разных пазлов.

## Размеры пазлов

В приложении предусмотрены четыре размера игрового поля:

| Размер | Количество элементов |
|---|---:|
| 3×3 | 9 |
| 4×4 | 16 |
| 5×5 | 25 |
| 6×6 | 36 |

Для каждого размера отдельно сохраняются лучший результат по времени и минимальное количество ходов.

## Локальные данные

Приложение хранит пользовательский прогресс локально:

- историю игровых событий;
- состояние коллекции и разблокированные фигурки;
- лучшие результаты для каждого пазла и размера сетки;
- настройки приложения.

Данные сохраняются на устройстве и не требуют регистрации или подключения к серверу.

## Сборка проекта

1. Склонируйте репозиторий:

```bash
git clone https://github.com/dareart03/PuzzleARKotlin.git
```

2. Откройте проект в Android Studio.
3. Настройте `local.properties` и добавьте ключ EasyAR.
4. Добавьте по примеру папку со своим паззлом в `app/src/main/assets/puzzles/`
5. Дождитесь завершения Gradle Sync.
6. Подключите Android-устройство или запустите эмулятор, если он поддерживает необходимые AR-функции.
7. Запустите конфигурацию приложения.

Для сборки APK из терминала Windows можно использовать:

```powershell
.\gradlew.bat :app:assembleDebug
```

Готовый APK будет находиться в:

`app/build/outputs/apk/debug/`
